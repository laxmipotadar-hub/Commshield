## 2. Feature Availability and Missing Protocol Fields

The 5G-NIDD dataset consists of flow-level network records generated by the Argus flow auditor over a 5G testbed UPF interface.

### A. Flow Features That Exist in Captures
- **Timing & Rates**: `StartTime`, `LastTime`, `Dur`, `Mean`, `StdDev`, `Rate`, `SrcRate`, `DstRate`
- **Addressing**: `SrcAddr` (IPv4), `DstAddr` (IPv4), `Proto` (TCP/UDP/ICMP), `Sport`, `Dport`
- **Volume & Metrics**: `TotPkts`, `SrcPkts`, `DstPkts`, `TotBytes`, `SrcBytes`, `DstBytes`, `TcpRtt`, `SynAck`, `AckDat`
- **Ground Truth Labels**: `Label` (Benign/Malicious), `Attack Type`, `Attack Tool`

### B. 3GPP Signaling, GTP-U, and Identity Fields (Do NOT Exist)
The 5G-NIDD dataset contains **zero** 3GPP control-plane or encapsulation headers:
1. **No GTP-U Fields**:
   - No `TEID` (Tunnel Endpoint Identifier)
   - No GTP-U sequence numbers or extension headers.
2. **No 3GPP Control-Plane Signalling**:
   - No NAS (Non-Access Stratum) registration, authentication, or security mode messages.
   - No NGAP (N2 interface) signaling counters.
   - No PFCP (Packet Forwarding Control Protocol / N4 interface) session establishment, modification, or deletion counters.
3. **No Subscriber Identity Fields**:
   - No `IMSI`, `SUPI`, `PEI`, `IMEI`, `TMSI`, or `5G-GUTI`.

### C. Labelled Proxies in Adapter
Because native 3GPP fields are absent, `FiveGNIDDAdapter` derives user-plane proxies (`LABELLED_PROXIES` in `ml_engine/preprocessing/adapters/fiveg_nidd.py`):
- `active_ue_count` $\leftarrow$ Count of unique source IP addresses (`nunique(src_addr)`)
- `pdu_sessions_established` $\leftarrow$ Count of active unique client flows
- `pdu_session_rate_per_ue` $\leftarrow$ Client flows divided by active unique IPs
- `gtpu_volume_per_ue` $\leftarrow$ Total bytes divided by active unique IPs
- `ue_hash_entropy` $\leftarrow$ Shannon entropy of source IP frequency distribution ($-\sum p_i \log_2 p_i$)
- `new_ue_rate` $\leftarrow$ Fraction of source IPs not observed in the preceding 60-second window
- Missing control-plane ratios (`nas_failure_ratio`, `pfcp_failure_ratio`, `registrations_per_active_ue`) default strictly to 0.0 without value fabrication.

## 3. Network Slice Assignment Mapping

In the raw 5G-NIDD capture files, **no 3GPP S-NSSAI (Single Network Slice Selection Assistance Information) tags exist** in flow headers. 

Slice identifiers are assigned by base station network topology:

- **Source File**: `ml_engine/preprocessing/adapters/fiveg_nidd.py`
- **Function**: `assign_slice_id(bs_identifier: Optional[str] = None) -> str` (lines 55–66)
- **Mapping**:
  - Base Station 1 (`BS1` / `BTS1`) $\rightarrow$ `sst-1-sd-010203` (Assigned to eMBB slice)
  - Base Station 2 (`BS2` / `BTS2`) $\rightarrow$ `sst-2-sd-010203` (Assigned to URLLC slice)
- **Disclosure Rule**: Every UI view, API response, and documentation table referencing 5G-NIDD slice metrics must carry the explicit label **"slices assigned"** to communicate that slices are topology proxies rather than 3GPP protocol headers.
